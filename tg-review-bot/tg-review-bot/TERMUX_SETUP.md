# Установка бота в Termux (Android)

Код бота не менялся — это обычный Python-проект, он одинаково работает
и на Ubuntu-сервере, и в Termux. Отличия только в установке пакетов и в
том, как заставить его работать в фоне (в Termux нет systemd).

## 0. Что понадобится

- Установите **Termux** и (опционально, для автозапуска и wake-lock)
  **Termux:API** и **Termux:Boot** — **обязательно из одного и того же
  источника**: либо всё с [F-Droid](https://f-droid.org/packages/com.termux/),
  либо всё из GitHub-релизов проекта Termux. Смешивать Play Store и
  F-Droid версии нельзя, будет конфликт.
- Дайте Termux разрешение на хранилище (не обязательно для этого бота,
  но полезно): `termux-setup-storage`

## 1. Установка

```bash
pkg install -y git   # если ещё не установлен
git clone git@github.com:ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПО.git
# или просто скопируйте распакованный zip в Termux
cd НАЗВАНИЕ_РЕПО

bash install_termux.sh
```

Скрипт `install_termux.sh` поставит Python и все зависимости из
`requirements.txt`.

Если что-то из зависимостей всё же попросит компилятор (крайне
маловероятно для этого проекта, но бывает с некоторыми пакетами) —
доставьте инструменты сборки:

```bash
pkg install -y clang make rust
```

## 2. Настройка

```bash
cp .env.example .env
nano .env
```

Впишите `TELEGRAM_BOT_TOKEN` и `GOOGLE_API_KEY`, сохраните (Ctrl+O,
Enter, Ctrl+X).

## 3. Запуск

Простой вариант — запустить и оставить сессию Termux открытой:

```bash
bash start.sh
```

Скрипт `start.sh` дополнительно берёт `termux-wake-lock` (если
установлен пакет `termux-api`), чтобы Android не "усыплял" процесс.

### Чтобы бот продолжал работать при закрытом экране

1. Установите пакет `termux-api`: `pkg install termux-api` и приложение
   **Termux:API** из того же источника, что и сам Termux.
2. В настройках Android **отключите оптимизацию батареи** для Termux
   (Настройки → Приложения → Termux → Батарея → "Без ограничений").
   Без этого Android рано или поздно всё равно "убьёт" процесс.
3. Держите Termux в списке недавних приложений (не сворачивайте его
   через "закрыть все"), либо запускайте через `tmux`/`screen`, чтобы
   сессия жила отдельно от окна:

```bash
pkg install tmux
tmux new -s reviewbot
bash start.sh
# отключиться от сессии, не завершая бота: Ctrl+B, затем D
# вернуться позже: tmux attach -t reviewbot
```

### Автозапуск при перезагрузке телефона (опционально)

1. Установите **Termux:Boot** (тот же источник, что и Termux).
2. Один раз откройте приложение Termux:Boot — оно создаст папку
   `~/.termux/boot/`.
3. Создайте в ней скрипт:

```bash
mkdir -p ~/.termux/boot
cat > ~/.termux/boot/start-reviewbot.sh << 'EOF'
#!/data/data/com.termux/files/usr/bin/bash
cd ~/НАЗВАНИЕ_РЕПО
bash start.sh
EOF
chmod +x ~/.termux/boot/start-reviewbot.sh
```

Теперь бот будет пытаться запускаться при каждой загрузке телефона.

## 4. Важные оговорки именно для Android/Termux

- Телефон — не сервер: при перезапуске телефона, разрядке батареи,
  агрессивной "чистке фона" некоторых прошивок (особенно
  Xiaomi/MIUI, Huawei, некоторые Samsung) процесс может останавливаться
  несмотря на wake-lock. Для по-настоящему круглосуточной работы
  Ubuntu-сервер (как в первом варианте) надёжнее.
- Мобильный интернет/Wi-Fi могут отключаться в глубоком сне — это тоже
  может прерывать опрос Google Places API до следующего пробуждения.
- SQLite-файл (`reviewbot.db`) лежит прямо в папке проекта в
  файловой системе Termux — она не теряется при простом закрытии
  приложения, только при удалении Termux или очистке его данных.

## 5. Проверка, что всё работает

```bash
tail -f nohup.out   # если запускали через nohup
```

или просто смотрите вывод в окне tmux — при появлении новых отзывов в
логе будет `INFO ... Опрашиваю N мест на новые отзывы`.
