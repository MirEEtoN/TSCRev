# Telegram-бот: уведомления о новых отзывах Google Maps

Бот отслеживает добавленные вами компании в Google Maps и присылает в
Telegram уведомление о каждом новом отзыве: оценка звёздами, автор,
текст, аватар автора, кнопка перевода текста и кнопка-ссылка на карточку
места в Google Maps.

## ⚠️ Важно понимать заранее (ограничения Google, не бота)

- **Google Places API отдаёт не более 5 отзывов на место** (обычно
  самые новые/релевантные). Если у компании отзывы появляются очень
  часто, часть новых отзывов может «проскочить» между опросами и не
  попасть в эти 5 — это ограничение API, а не бага бота.
- **Фотографий, прикреплённых к самому отзыву, Google Places API не
  отдаёт.** Доступен только аватар автора (`profile_photo_url`), его
  бот и присылает вместе с текстом. Полноценные фото отзывов есть
  только у платных сторонних сервисов (например, SerpApi Google Maps
  Reviews API) — при желании под такой источник легко завести отдельный
  адаптер вместо `google_places.py`, остальной код бота трогать не
  придётся.
- У Google Places API есть квота и стоимость запросов — не ставьте
  `POLL_INTERVAL_SECONDS` слишком маленьким и не добавляйте сотни мест
  без необходимости.

## 1. Подготовка на стороне Google

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/),
   создайте проект (или используйте существующий).
2. Включите API: **Places API**.
3. Создайте API-ключ в разделе *APIs & Services → Credentials*.
4. (Рекомендуется) Ограничьте ключ только Places API и, если возможно,
   по IP вашего сервера.
5. Подключите биллинг — без него Places API работать не будет (у Google
   есть бесплатный ежемесячный лимит).

## 2. Подготовка бота в Telegram

1. Напишите [@BotFather](https://t.me/BotFather), выполните `/newbot`,
   получите токен вида `123456:AA...`.

## 3. Установка на Ubuntu

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip

# распакуйте/скопируйте проект, например в ~/tg-review-bot
cd ~/tg-review-bot

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
nano .env   # впишите TELEGRAM_BOT_TOKEN и GOOGLE_API_KEY
```

Проверка ручным запуском:

```bash
source venv/bin/activate
python3 main.py
```

Если в логах написано «Бот запущен» — всё в порядке, идите в Telegram и
нажмите `/start`.

## 4. Автозапуск через systemd (чтобы бот работал постоянно)

1. Отредактируйте `reviewbot.service`: укажите реального пользователя
   (`User=`) и правильные пути (`WorkingDirectory=`, `ExecStart=`,
   `EnvironmentFile=`).
2. Установите юнит:

```bash
sudo cp reviewbot.service /etc/systemd/system/reviewbot.service
sudo systemctl daemon-reload
sudo systemctl enable reviewbot
sudo systemctl start reviewbot
```

3. Проверка статуса и логов:

```bash
sudo systemctl status reviewbot
sudo journalctl -u reviewbot -f
```

## 5. Команды бота

| Команда      | Что делает                                                        |
|--------------|--------------------------------------------------------------------|
| `/start`     | Регистрирует вас и показывает краткую справку                     |
| `/addplace`  | Добавить новое место (по названию+городу или по ссылке Google Maps) |
| `/myplaces`  | Список ваших мест: кнопки 🔔/🔕 (вкл/выкл уведомления) и ❌ (удалить) |
| `/cancel`    | Отменить текущее добавление места                                  |
| `/help`      | Справка                                                             |

При добавлении места бот покажет несколько найденных вариантов —
нажмите на нужный, чтобы подтвердить.

В самом уведомлении о новом отзыве есть кнопки:

- **🌐 Перевести** — открывает список языков, после выбора языка бот
  пришлёт перевод отдельным сообщением (само уведомление не портится).
- **🔗 Открыть на картах** — ссылка на карточку компании в Google Maps
  (сам API не даёт прямую ссылку на конкретный отзыв, только на
  карточку заведения, где отзывы можно отсортировать по новизне).

## 6. Как это работает внутри

- Раз в `POLL_INTERVAL_SECONDS` (по умолчанию 10 минут) бот запрашивает
  у Google Places Details API до 5 последних отзывов по каждому месту,
  на которое хоть у кого-то включены уведомления.
- Каждый отзыв хешируется по (`place_id`, автор, время) и сравнивается с
  уже отправленными (таблица `seen_reviews` в SQLite) — так бот не
  присылает один и тот же отзыв повторно.
- Один и тот же отзыв рассылается всем, кто подписан на это место с
  включёнными уведомлениями.

## 7. Структура проекта

```
tg-review-bot/
├── main.py            # точка входа
├── config.py           # чтение .env
├── database.py         # SQLite: пользователи, места, подписки, история отзывов
├── google_places.py    # обёртка над Google Places API
├── translator.py       # перевод текста отзывов
├── keyboards.py         # inline-клавиатуры
├── handlers.py          # команды и обработка кнопок
├── scheduler.py         # периодический опрос и рассылка уведомлений
├── utils.py              # форматирование сообщений, хеш отзыва
├── requirements.txt
├── .env.example
└── reviewbot.service    # пример systemd unit
```
